템플릿 받아서 열고 /start

템플릿을 내 저장소로 복사해서 PC 로 받고, VS Code 로 열어 /start 를 칩니다. 그다음은 Claude 가 안내해요.

  • 10분
  • 필요: GitHub 계정 (없으면 아래 "계정 없이")

GitHub 계정으로 (권장)

  1. GitHub 가입 github.com/signup — 이미 있으면 건너뛰어요.
  2. "Use this template" → "Create a new repository" 받은 템플릿 주소(예: github.com/gnaak/base)로 가서 오른쪽 위 초록 버튼을 눌러요.
  3. 이름 정하고 만들기 Repository name 에 영문 이름을 쓰고, Private 를 고른 뒤 Create repository.
  4. 주소 복사 만들어진 저장소에서 초록 Code 버튼 → HTTPS 주소 옆 복사 버튼.
  5. VS Code 로 받기 VS Code 에서 Ctrl+Shift+P (Mac: ⌘+Shift+P) → Git: Clone → 주소 붙여넣기 → 저장할 폴더 고르기 → 오른쪽 아래 알림에서 열기.

계정 없이 (일단 시험만)

  1. ZIP 으로 받기 템플릿 페이지의 초록 Code → Download ZIP → 압축 풀기 → VS Code 에서 파일폴더 열기. 나중에 내 GitHub 에 올리고 싶으면 내 GitHub 에 올리기.

마지막 — /start

VS Code 의 Claude 패널에 /start 를 치고, 만들고 싶은 걸 한두 줄로 말해요. 예: /start 동네 원데이 클래스 예약 서비스

"이 폴더의 파일을 믿나요(Trust)?" 같은 창이 뜨면 믿음(Trust) 을 골라요 — 내가 받은 내 폴더예요.
