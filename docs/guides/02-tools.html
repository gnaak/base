uv · Node.js 설치

서버(파이썬)와 화면(Node.js)을 돌리는 도구예요. 파이썬은 따로 설치하지 않아요 — uv 가 필요한 버전을 알아서 받아 옵니다.

  • 5~10분
  • 보통은 Claude 가 대신 설치해요

Claude 가 설치할 때 (Windows)

  1. "예" 누르기 Claude 가 설치를 시작하면 "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 떠요. 예 를 눌러요.
  2. 그대로 기다리기 설치가 끝나면 Claude 가 알아서 이어서 해요. 드물게 "VS Code 를 껐다 켜 주세요" 라고 하면, 창을 모두 닫고 다시 연 뒤 Claude 패널에 /start 를 다시 쳐요. 했던 단계는 건너뛰고 이어서 해요.
