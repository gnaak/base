VS Code 와 Claude Code 설치

Claude 와 대화하면서 프로그램을 만드는 작업 공간을 준비합니다. 한 번만 하면 돼요.

  • 10분
  • 필요: Claude 유료 플랜(Pro 이상) 계정
  • Windows · macOS

순서

  1. VS Code 설치 code.visualstudio.com 에서 내려받아 설치해요. 설치 옵션은 기본값 그대로 두면 돼요.
  2. (Windows 만) Git 설치 git-scm.com/download/win 에서 내려받아 설치해요. 질문이 많이 나오는데 전부 기본값으로 Next 를 누르면 돼요. VS Code 와 Claude Code 가 내부적으로 씁니다.
  3. Claude Code 확장 설치 VS Code 왼쪽 세로 막대에서 확장(네모 네 개 아이콘)"Claude Code" 검색게시자 Anthropic 확인설치
  4. 로그인 VS Code 에 생긴 Claude 아이콘을 눌러 패널을 열고 로그인 버튼을 눌러요. 브라우저가 열리면 Claude 계정으로 승인해요.
  5. 편집 자동 승인 켜기 (권장) Claude 입력창 근처의 모드 선택에서 편집을 자동으로 허용하는 모드를 골라요 (이름은 버전에 따라 조금 달라요). 꺼져 있으면 파일을 고칠 때마다 "허용할까요?" 를 물어서, 자리를 비운 사이 일이 멈춰요.

막히면

  • 회사 PC 라 설치가 막혀요 — 관리자 권한이 필요해요. 사내 IT 에 VS Code · Git 설치를 요청해요
