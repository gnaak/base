Docker 없이 MySQL 직접 설치

Docker Desktop 을 못 쓰는 PC 일 때만 이 방법을 써요. 할 수 있다면 Docker Desktop 쪽이 훨씬 간단해요.

  • 20~40분
Redis 는 설치하지 않아도 돼요

로그인 상태를 기억하는 Redis 는 내 PC 에서는 Claude 가 메모리로 대신해요. 실제 서버에는 배포할 때 자동으로 깔려요.

Windows

  1. MySQL 설치 dev.mysql.com/downloads/installer 에서 MySQL Installer 를 받아 Server only 로 설치해요. 중간에 root 비밀번호를 정하라고 하면 정하고 적어 둬요.
  2. Claude 에게 "다 했어요" Claude 가 설정 파일(backend/.env)을 메모장으로 열어 줘요. 알려 주는 줄에 비밀번호를 직접 적고 저장해요. 비밀번호를 대화창에 쓰지 마세요 — 대화 기록에 남아요.

macOS

Homebrew 가 있으면 터미널에서:

brew install mysql
brew services start mysql
됐는지 확인

Claude 에게 "다 했어요" 를 누르면 접속을 확인해요 (prepare_local check).
