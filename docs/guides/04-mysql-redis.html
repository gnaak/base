Docker 없이 MySQL · Redis 직접 설치

Docker Desktop 을 못 쓰는 PC 일 때만 이 방법을 써요. 할 수 있다면 Docker Desktop 쪽이 훨씬 간단해요.

  • 20~40분

Windows

  1. MySQL 설치 dev.mysql.com/downloads/installer 에서 MySQL Installer 를 받아 Server only 로 설치해요. 중간에 root 비밀번호를 정하라고 하면 정하고 적어 둬요.
  2. Redis 설치 Windows 용 공식 Redis 는 없어요. Redis 와 똑같이 동작하는 Memurai Developer(무료)를 설치해요. 설치하면 자동으로 켜져요.
  3. Claude 에게 알려 주기 "MySQL root 비밀번호는 ○○ 이야" 라고 말해 주면 Claude 가 설정 파일(backend/.env)에 넣고 이어서 해요.

macOS

Homebrew 가 있으면 터미널에서:

brew install mysql redis
brew services start mysql
brew services start redis
됐는지 확인

Claude 에게 "했어" 라고 말하면 접속을 확인해요 (prepare_local check).
