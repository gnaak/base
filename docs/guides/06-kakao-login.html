카카오 로그인 키 받기

"카카오로 시작하기" 버튼이 실제로 동작하려면 카카오에 내 서비스를 등록하고 키 두 개를 받아야 해요. 로그인 기능 자체는 이미 만들어져 있어서, 키만 넣으면 돼요.

  • 20~30분
  • 필요: 카카오 계정 · 휴대폰 본인인증
  • 무료
예전 블로그 글과 화면이 달라요

카카오 개발자 사이트가 2025년 12월에 바뀌었어요. 주소 등록(리다이렉트 URI)이 [앱] → [플랫폼 키] → [REST API 키] 안으로 옮겨졌어요. 예전 글의 "[카카오 로그인] → [일반]" 에서 찾으면 없어요.

순서

  1. 앱 만들기 developers.kakao.com/console/app 에 카카오 계정으로 로그인 → 애플리케이션 추가 → 앱 이름(서비스 이름)을 적고 저장해요. 앱 아이콘도 이때 올려 두면 좋아요 — 4번에서 필요해요.
  2. 카카오 로그인 켜기 왼쪽 메뉴 [카카오 로그인] → [사용 설정] 에서 상태를 ON 으로 바꿔요.
  3. 주소(리다이렉트 URI) 등록 · 키 확인 [앱] → [플랫폼 키] → [REST API 키] 로 가요. 여기에 세 가지가 있어요.
    • REST API 키 — 첫 번째 키예요. 아래 5번에서 써요
    • 리다이렉트 URI — 아래 주소를 한 줄에 하나씩 등록해요. 글자 하나라도 다르면 로그인 때 KOE006 오류가 나요 
      http://localhost:3000/kakao/login
      서버에 올린 뒤에는 https://내도메인/kakao/login 도 한 줄 더 추가해요 (http · https 를 구분해요)
    • 클라이언트 시크릿 — 두 번째 키예요. 켜져 있는지 확인하고 값을 확인해요
  4. 이메일을 받을 수 있게 — 개인 개발자 비즈 앱 전환 이 서비스는 이메일이 확인된 카카오 계정만 로그인시켜요 (같은 이메일로 다른 계정이 가로채지 못하게). 그런데 카카오는 이메일을 "필수"로 받는 걸 비즈 앱에만 허락해요. 사업자가 없어도 돼요:
    • 오른쪽 위 내 계정 → [계정 설정] → [본인인증] 에서 휴대폰 본인인증
    • [앱] → [일반] 에 앱 아이콘이 있는지 확인
    • [앱] → [일반] → [비즈니스 정보] 에서 개인 개발자 비즈 앱 전환 → 약관 동의. 예전엔 심사가 있었는데 지금은 바로 바뀌어요
  5. 받을 정보(동의항목) 고르기 [카카오 로그인] → [동의항목] 에서:
    • 카카오계정(이메일) — 필수 동의 (4번을 해야 고를 수 있어요)
    • 닉네임 — 필수 또는 선택
    • 프로필 사진 — 선택 (없어도 돼요)
  6. 키를 설정 파일에 적기 — 대화창에 붙여 넣지 마세요 Claude 에게 "카카오 키 받았어요" 라고 하면 설정 파일 두 개를 메모장으로 열고 몇 번째 줄인지 알려 줘요. 직접 붙여 넣고 저장해요.
    파일줄넣을 값
    backend/.envkakao_client_id=REST API 키
    backend/.envkakao_client_secret=클라이언트 시크릿
    frontend/.envVITE_APP_PUBLIC_KAKAO_REST_API_KEY=REST API 키 (위와 같은 값)

    리다이렉트 주소 줄(local_kakao_redirect_uri)은 이미 http://localhost:3000/kakao/login 으로 적혀 있어요. 그대로 두면 돼요.

됐는지 확인

화면을 다시 띄우고(Claude 에게 "다시 켜 줘") 첫 화면의 카카오 버튼을 눌러요. 카카오 동의 화면 → 내 서비스로 돌아와 로그인되면 끝이에요.

막히면

  • KOE006 — 등록한 주소와 실제 주소가 달라요. http / https, 끝의 /, 포트(:3000)까지 똑같은지 봐요
  • 리다이렉트 URI 입력칸이 안 보여요 — 예전 위치를 보고 있어요. [앱] → [플랫폼 키] → [REST API 키]
  • 이메일을 "필수 동의"로 못 바꿔요 (회색) — 아직 비즈 앱이 아니에요. 4번
  • 주소가 맞는데도 안 돼요 — 웹 사이트 도메인 등록을 요구하는 경우가 있어요. [앱] → [일반] → [플랫폼] → [웹] 에 http://localhost:3000 을 넣어 봐요
  • 로그인했는데 "이메일 동의가 필요" 오류 — 동의 화면에서 이메일을 빼고 동의했어요. 5번에서 이메일을 필수로 하면 다시 안 생겨요
서버에 올릴 때

운영 서버의 키는 이 파일이 아니라 AWS Parameter Store 에 넣어요 (infra/README.md 의 "OAuth · 외부 API 키"). 그리고 3번의 리다이렉트 URI 에 https://내도메인/kakao/login 을 추가해요.
