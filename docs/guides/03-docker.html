Docker Desktop 설치

서비스의 데이터를 담는 MySQL 과 로그인 상태를 기억하는 Redis 를 한 번에 띄워 주는 프로그램이에요. 설치만 하면 실행은 Claude 가 합니다.

  • 15~30분
  • 재부팅이 필요할 수 있어요
  • 디스크 수 GB
회사에서 쓴다면

Docker Desktop 은 개인 · 교육 · 작은 회사(직원 250명 미만이면서 매출 1천만 달러 미만)는 무료이고, 그보다 큰 회사는 유료 구독이 필요해요. 해당되면 직접 설치 쪽을 보세요.

순서 (Windows)

  1. 설치 파일 받기 Claude 가 대신 설치하면 이 단계는 건너뛰어요 ("예" 만 누르면 돼요). 직접 받으려면 docker.com/products/docker-desktop → Download for Windows.
  2. 설치 Use WSL 2 체크는 켠 그대로 OK. 끝나면 다시 시작하라고 하면 다시 시작해요.
  3. 처음 실행 Docker Desktop 을 열고 약관에 Accept. 로그인 · 설문은 건너뛰어도(Skip) 돼요.
  4. "WSL 업데이트" 안내가 뜨면 PowerShell 을 열고 아래를 친 뒤 Docker Desktop 을 다시 열어요. 안 뜨면 건너뛰어요. 
    wsl --update
  5. 켜졌는지 보기 왼쪽 아래가 초록색 Engine running 이면 끝이에요. 이제 Claude 에게 "했어" 라고 말해요.

macOS

같은 페이지에서 내 Mac 칩(Apple / Intel)에 맞는 파일을 받아 응용 프로그램 폴더로 끌어다 놓고 실행해요. 위 3·5 와 같아요.

막히면

  • "Virtualization ... disabled" · 가상화가 꺼져 있다고 나와요 — PC 설정(BIOS)에서 가상화(Intel VT-x / AMD-V)를 켜야 해요. 제조사마다 방법이 달라서 "PC 모델명 + BIOS 가상화" 로 찾아요. 어려우면 직접 설치
  • 매번 켜야 하나요? — PC 를 켤 때 Docker Desktop 도 켜져 있어야 서비스가 돌아요. 설정의 Start Docker Desktop when you sign in 을 켜 두면 편해요
