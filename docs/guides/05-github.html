내 GitHub 에 올리기

만든 코드를 온라인에 보관해요. PC 가 고장 나도 남고, 나중에 서버에 올릴 때(자동 배포)도 여기서 가져가요.

  • 5분
  • 필요: GitHub 계정

"Use this template" 으로 만들었다면 이미 내 저장소와 연결돼 있어요 — 이 페이지는 필요 없어요.

순서

  1. 빈 저장소 만들기 github.com/new → 이름 쓰기 → Private → Add a README 는 끈 채로 → Create repository.
  2. 주소 복사 만들어진 페이지 위쪽의 HTTPS 주소를 복사해요.
  3. Claude 에게 맡기기 "이 주소로 올려 줘: (붙여넣기)" 라고 말하면 Claude 가 아래 두 줄을 실행해요. 처음 한 번은 GitHub 로그인 창이 떠요 — 로그인해서 승인해요. 
    git remote add origin https://github.com/내아이디/저장소이름.git
git push -u origin main
무인 실행 중에는

/autopilot 이 도는 동안에는 올리기(push)가 막혀 있어요. 결과를 확인한 뒤 직접 올려요.
